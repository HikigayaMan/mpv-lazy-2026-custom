## 下载和安装

下载 `mpv-lazy-2026-custom-cumulative-update-v2026.10.12-progress.zip`，使用同时发布的 SHA256SUMS 校验。关闭当前安装的 MPV 和 B站中继，将 ZIP 内容直接合并到 `mpv.exe` 所在目录；在 Tampermonkey／Violentmonkey 导入包内 `external_player.user.js`，禁用重复旧脚本、关闭上游自动更新，完整刷新网页。

这是更新包，需要原项目 `v2026.06` 可运行安装及最新原版 config；首次安装与 BrowserRelay 注册步骤见 [README](https://github.com/HikigayaMan/mpv-lazy-2026-custom/blob/v2026.10.12-progress-update/README.MD)。AI 运行时和模型继续由原项目提供。用户偏好、Cookie、授权信息、历史、缓存和日志不包含在包内。

## 本次双向进度更新

- **网页 → MPV／MPVNET**：从当前网页或最近保存的位置续播，支持普通 BV／av 视频及分 P，普通有限时长网页视频支持本机续播。
- **MPV → 网页和 B站账号**：播放器观看、拖动、暂停与退出的位置回写原网页，保存本机记录；登录 B站时通过原网页写入账号观看历史。真实测试中 MPV 跳转 187.5 秒后，网页同步到相同位置，账号历史显示 `03:07 / 06:20`。
- **正确保存与隔离**：倒退和零秒按最新操作保存，分 P 不混用位置；品质切换的加载零秒不会抹掉位置；手动退出不误标看完。网页主动恢复播放或拖动时接管记录，后台旧请求不会覆盖新播放器会话。
- **浏览器兼容**：WebSocket 无法连接时使用匿名 HTTP 进度通道；修复健康检测、超时、刷新重连和失败会话清理。认证和 CSRF 只留在浏览器，不发送给中继。
- **MPV 参数修复**：.19 分别发送两个 Lua 参数，包内 Lua 同时兼容已导入 .18 的旧格式。已完成手动进度更新的 .18 用户可继续使用；首次安装和其余升级用户导入包内 .19。
- **关闭与权限**：双向进度及账号历史默认开启，可分别关闭。原网页关闭后仍保存本机位置；账号历史需要登录网页保持打开，重新进入同一视频可补同步。直播、番剧影视和互动分支不套用点播续播。

## 累计新增与修复

- **B站直播弹幕**：网页交接视频时创建独立弹幕会话，支持短房间号、iframe／资源嗅探交接、重连和认证刷新、暂停丢弃与退出清理。弹幕失败显示原因并允许视频继续启动。
- **表情文本**：保留文字及表情标签，图片表情显示名称，无名称使用 `[表情]`。
- **流品质**：点播／直播传递实际可用品质，优先最高可用；修复菜单转圈，支持播放器内切换。点播保留音轨、位置及暂停，同房间直播保留弹幕会话和显示状态。
- **同画质备用源**：选择 B站 API 返回的标准 HTTPS 备用源，修复部分特殊端口 PCDN 源连接失败，保留画质、编码和签名。
- **设置自动保存**：视频滤镜、着色器、画面设置和弹幕开关／样式在重启后恢复；清空选择也保存，自动画面预设和临时弹幕滤镜不会误写入。
- **普通视频弹幕一致性**：普通视频／直播统一开关、样式、速度、显示区域与帧率；首次默认显示，明确关闭继续保留，暂停可刷新样式，旧 `b` 入口转交统一插件。
- **网页全屏启动**：移交 MPV／MPVNET 后默认全屏播放。
- **缓存缩略图**：播放条悬停显示附近关键帧，网络视频只使用已缓存内容，不额外请求视频 URL；未缓存位置清图，切换／驱逐清理临时文件，快捷键和按钮统一到同一引擎。
- **自动移交**：可选进入视频／直播页面后自动启动已启用的默认播放器，默认关闭；支持新内容识别与去重，失败可手动重试。
- **构建与诊断**：增加会话失败阶段、跨实例／缓存／品质回归测试，累计 ZIP 内含源提交、完整差异、逐文件哈希和 EXE 公开构建信息。
